# Performance & Accessibility Checklist

Complete this checklist before shipping.

## Performance

- [ ] Run Lighthouse in Incognito
- [ ] LCP ≤ 2.5s
- [ ] CLS ≤ 0.1
- [ ] JS bundle ≤ 150 KB (gzip)
- [ ] CSS ≤ 40 KB (gzip)
- [ ] Fonts use `font-display: swap`
- [ ] Images have width/height

## Accessibility (WCAG 2.2 AA)

- [ ] Page has landmarks (header, main, footer, nav)
- [ ] Skip to content link works
- [ ] Focus ring visible on all interactive elements
- [ ] Tab order is logical
- [ ] Primary buttons ≥ 44×44px
- [ ] Body text contrast ≥ 4.5:1 (both themes)
- [ ] Keyboard navigation works
- [ ] Reduced motion respected

## Theme Testing

- [ ] Atlas Light
- [ ] Atlas Dark
- [ ] Folio Light
- [ ] Folio Dark
- [ ] Maison Light
- [ ] Maison Dark

## Responsive Testing

- [ ] Mobile 375px
- [ ] Tablet 768px
- [ ] Desktop 1440px
